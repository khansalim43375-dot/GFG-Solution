# [Maximum Level in Binary Tree](https://www.geeksforgeeks.org/problems/maximum-depth-of-binary-tree/1)
## Easy
Given a binary tree, find its maximum level (the deepest level that contains at least one node). Root is considered at level 1.Examples :Input: root = [1, 3, 2, 4, N, N, N]Output: 3Explanation: The farthest leaf node is 4, which is located at level 3.Input: root = [10, 20, 30, N, 40, N, 60, N, N, 2, N, N, N]
Output: 4
Explanation: The farthest leaf node is 2, which is located at level 4.
