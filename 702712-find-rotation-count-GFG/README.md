# [Find Rotation Count](https://www.geeksforgeeks.org/problems/rotation4723/1)
## Easy
Given an increasing sorted rotated array arr[] of distinct integers. The array is right-rotated&nbsp;k&nbsp;times. Find the value of&nbsp;k.Examples:Input: arr[] = [5, 1, 2, 3, 4]
Output: 1
Explanation: The given array is [5, 1, 2, 3, 4]. The original sorted array is [1, 2, 3, 4, 5]. We can see that the array was rotated 1 times to the right.Input: arr = [1, 2, 3, 4, 5]
Output: 0
Explanation: The given array is not rotated.Input: arr = [6, 9, 2, 4]
Output: 2
Explanation: The original array is [2, 4, 6, 9] and we get the above array after two rotations.
