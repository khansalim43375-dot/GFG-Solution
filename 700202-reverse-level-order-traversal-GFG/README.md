# [Reverse Level Order Traversal](https://www.geeksforgeeks.org/problems/reverse-level-order-traversal/1)
## Medium
Given a binary tree, find its reverse level order traversal. i.e.,&nbsp; the traversal begins from the last level. 
Examples :
Input: root = [1, 3, 2]
Output: [3, 2, 1]
Explanation: Traversing level 1 : 3 2, Traversing level 0 : 1
Input: root = [10, 20, 30, 40, 60]

Output: [40, 60, 20, 30, 10]
Explanation: Traversing level 2 : 40 60, Traversing level 1 : 20 30, Traversing level 0 : 10
Input: root = [1, 2, 3]
Output: [2, 3, 1]
Constraints:1 ≤ n ≤ 105
