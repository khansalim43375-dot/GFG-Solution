# [Nodes at K Distance from Root](https://www.geeksforgeeks.org/problems/k-distance-from-root/1)
## Easy
Given a root of binary tree having n nodes and an integer k, return all nodes that are at distance k from the root (root is considered at distance 0 from itself). Nodes should be returned from left to right.
Examples:
Input: k = 0, root = [1, 3, 2]Output: 1Explanation: 1 is the only node which is 0 distance from the root 1.

Input: k = 3, root = [1, 2, N, N, 1, 5, 3] 
Output: 5 3Explanation:  5 and 3 are the nodes which are at distance 3 from the root 1, returned from left to right.
