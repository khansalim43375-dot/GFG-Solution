# [Single in Array of Triples](https://www.geeksforgeeks.org/problems/find-element-occuring-once-when-all-other-are-present-thrice/1)
## Medium
Given an array of integers&nbsp;arr[]&nbsp;where,&nbsp;every element&nbsp;appears&nbsp;thrice&nbsp;except for one which&nbsp;occurs&nbsp;once.Find that element which&nbsp;occurs&nbsp;once.Examples:Input: arr[] = [1, 10, 1, 1]
Output: 10
Explanation: 10 occurs once in the array while the other element 1 occurs thrice.
Input: arr[] = [3, 2, 1, 34, 34, 1, 2, 34, 2, 1]
Output: 3
Explanation: All elements except 3 occurs thrice in the array.
